## 外部配置核验依据（2026-09-18）

- [CloudBase AI Node SDK](https://docs.cloudbase.net/ai/model/nodejs-access) 建议 AI 请求使用 60000ms 或更长超时；这是该 SDK 的建议，不能直接视为本项目自写 HTTP 封装的必选值。
- [CloudBase 云函数配置](https://docs.cloudbase.net/cli-v1/functions/configs) 当前列出 `timeout` 默认 5 秒、范围 1–900 秒。这是该配置接口的口径；本项目实际环境仍需控制台核验，不写死“默认 20 秒、最大 60 秒”。
- [百炼 Qwen-VL 兼容接口](https://help.aliyun.com/en/model-studio/qwen-vl-compatible-with-openai)、[百炼地域与配置](https://www.alibabacloud.com/help/zh/model-studio/what-is-model-studio)、[腾讯混元视觉模型](https://cloud.tencent.cn/document/product/1729/104753) 可用于候选筛选；支持图像输入、账号权限及云端可达性均须实测。
